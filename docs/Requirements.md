# Functional Requirements

## Search

Support:

- Punjabi Word Search
- Punjabi Initial Search
- English (Roman Punjabi) Word Search
- English Initial Search

Search should auto-detect input.

No search mode selector should be required.

---

## Voice Search

Primary feature.

User presses microphone.

Speaks Gurbani.

Releases button.

Search starts automatically.

Voice search should primarily use Initial Search rather than Word Search.

---

## Database

SQLite.

Offline.

Downloaded once.

Locally cached.

---

## Keyboard

Integrated Punjabi keyboard.

No external keyboard required.

---

## Performance

Target search latency:

<50ms

Database:

150,000+ lines

---

## UI

Material 3

Responsive

Tablet friendly

Desktop friendly

Dark mode

Animations

---

# Development Rules

Each milestone should satisfy:

- Compiles
- Runs
- Tested
- No known crashes
- Production quality

The developer must stop after completing a milestone.

The next milestone begins only after manual approval.
