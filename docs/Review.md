# Review Process

The project should be developed milestone-by-milestone.

Each milestone must be:

- fully implemented
- compile successfully
- run successfully
- tested by Codex
- documented

After completing ONE milestone,

STOP.

Do not continue automatically.

Wait for my approval.

I will:

- test manually
- report bugs
- report UX issues
- request improvements

Only after receiving approval should the next milestone begin.

If I report bugs,

those bugs become part of the NEXT milestone.

Never leave technical debt behind.

Every milestone should end in a stable state.
